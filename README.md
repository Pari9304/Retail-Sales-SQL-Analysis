# Retail Sales SQL Analysis

## Project Overview

This project analyzes retail sales data using SQL to generate business insights related to product performance, regional sales trends, store performance, revenue growth, and key business KPIs.

The project demonstrates how SQL can be used for data extraction, reporting, and business intelligence by working with a relational retail sales database.

---

## Objectives

- Analyze sales performance across regions and stores
- Identify top-selling products and categories
- Track monthly sales trends and growth
- Measure store and manager performance
- Calculate key business KPIs
- Generate actionable insights from retail sales data

---

## Database Schema

The project consists of three relational tables:

### Products
Contains product information such as:
- Product ID
- Product Name
- Category
- Price

### Stores
Contains store details including:
- Store ID
- Store Name
- Region
- Manager

### Sales
Contains transactional sales records including:
- Sale ID
- Sale Date
- Store ID
- Product ID
- Quantity Sold
- Total Amount

## Business Questions Solved

### Sales Performance Analysis
- View complete sales transactions with product and store details
- Calculate total sales by region
- Analyze category-wise sales performance

### Product Analysis
- Identify top-selling products by revenue
- Find the highest-performing products within each region

### Store Performance
- Rank stores by total revenue
- Identify top-performing store managers
- Calculate average order value by store

### Trend Analysis
- Analyze monthly sales trends
- Measure month-over-month sales growth

### KPI Dashboard Metrics
- Total Revenue
- Total Transactions
- Average Transaction Value
- Number of Products Sold
- Number of Stores Involved

---

## Key Insights

### Regional Performance
Analyzed sales distribution across different regions to identify high-performing markets.

### Product Performance
Evaluated product revenue contribution and category-level sales trends.

### Store Efficiency
Compared store managers and stores based on total sales and average order value.

### Revenue Growth
Tracked month-over-month revenue changes using SQL window functions.

### Business KPIs
Generated executive-level KPIs for performance monitoring and decision-making.
